# Frontend — Mecanízame

Dashboard web del CRM Mecanízame (React 19 + TypeScript + Vite + Tailwind CSS v4).

Ver el [README raíz](../README.md) para el stack completo, la estructura y cómo correr el proyecto.

## Scripts

```bash
cp .env.example .env.local   # variables de Supabase local
npm install
npm run dev                  # http://localhost:5173
npm run build                # tsc -b && vite build
npm run typecheck            # solo chequeo de tipos
npm run lint
npm run preview
```

El alias `@/` apunta a `src/`.
